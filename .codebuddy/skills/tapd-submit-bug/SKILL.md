---
name: tapd-submit-bug
description: >-
  提交 TAPD 缺陷（bug）并上传截图、日志或录屏附件；创建完成后自动搜索并关联需求（story）；
  支持 dry-run 草稿预览、前端/后端模块路由、简单问题标签、标题格式化与附件失败幂等恢复。
  当用户说要提 bug、提单、报 bug、报缺陷、登记缺陷、录缺陷、提交缺陷、创建 TAPD 工单、把问题提交/录入 TAPD、截图提单、带图提 bug、上传 bug 截图或日志、帮我提交这个问题、这个问题记到 TAPD、预览缺陷单/草稿、确认提交、重试附件上传，或附带问题描述/复现步骤/截图要求写入 TAPD 时使用。
  需配置 .tapd/tapd_env.json（认证）与 project_config.json（项目）。
